## แผนแก้เฉพาะจุด

### 1. Extension: เตรียมเครื่องมือแบบรอและตรวจใหม่ได้

- แยกเหตุเป็นcomposer_not_ready, opener_missing/disabled, menu_missing/ambiguous, option_detached, chip_unconfirmed, response_active, draft_changedและowner_changed
- รอcomposer+form+openerให้พร้อมและคงที่ในหน้าของคำขอเดิมแบบยกเลิกได้ ค้นnodeใหม่เมื่อเว็บremount ไม่ตัดสินจากการอ่านครั้งเดียว
- ถ้าเมนูหรือchipเปลี่ยนระหว่างโหลด ให้ตรวจสถานะปัจจุบันก่อนคลิกอีกครั้ง ถ้าchipเลือกแล้วให้ทำต่อ ไม่เปิดปิดโหมดซ้ำ
- เก็บphase=preparing/recoveringและstage/reason/attempt/เวลาตรวจล่าสุด โดยไม่บันทึกข้อความพรอมต์ รูป หรือข้อมูลบัญชี
- ยืนยันrequest/tab/document/ownerเดิม และไม่มีSendที่รับแล้วหรือผลไม่แน่ชัด ก่อนอนุญาตเตรียมต่อ; ถ้าAIกำลังทำงานให้รอ หากพบdraftของผู้ใช้ให้เก็บไว้
- ส่งคำขอปกได้เมื่อเลือกเครื่องมือและตรวจรูปอ้างอิงครบแล้วเพียงครั้งเดียว ไม่เพิ่มการกดSendเพื่อแก้ปัญหาก่อนส่ง

### 2. โปรแกรม: แยก “ยังไม่ส่ง” จาก “ส่งแล้วรอผล”

- ให้cover event/ledgerรับและตรวจชนิดข้อมูลerror_code, preparation_stage/reason, attemptและหลักฐานnever-dispatchedที่ผูกrequest/document
- งานที่พิสูจน์ว่าไม่เคยส่งยังเป็นrecoveringและลองเตรียมต่อหลังเว้นช่วง ไม่เปลี่ยนเป็นneeds_reviewเพียงเพราะปุ่มยังโหลดไม่ครบ
- ถ้าหน้าเดิมยังเตรียมไม่ได้หลังรอและตรวจใหม่ ให้รีเฟรชหรือตั้งหน้าใหม่เฉพาะคำขอที่พิสูจน์never-dispatched พร้อมบันทึกการส่งต่อผู้รับงาน ป้องกันตัวเก่าส่งซ้อน
- งานaccepted/unknown Sendต้องเข้าอ่านผลเดิม; ไม่ใช้ข้อความerrorเก่าหรือการไม่มีfieldเพียงอย่างเดียวเป็นสิทธิ์ส่งซ้ำ
- เก็บFinal รูป เสียง และข้อมูลคิวเดิม แก้เฉพาะงานปก เมื่อปกบันทึกสำเร็จให้gateปล่อยงานต่อเฉพาะคิวที่ไม่ได้ถูกผู้ใช้สั่งพัก ไม่เปลี่ยนmanual pause

### 3. UX/UI: ปุ่มกู้ตรงสถานะ

- preparing/recovering: แสดง “วิดีโอเสร็จแล้ว • กำลังเตรียมสร้างปก” พร้อมเหตุสั้นและความคืบหน้า
- never-dispatched: เสนอ “ทำปกต่อ” แทน “ดึงปกเดิมจากเว็บ”
- accepted/unknown: เสนอ “ตรวจ/ดึงผลปกเดิม” และแสดงกำลังรอเมื่อยังสร้าง
- ready: แสดงภาพปกที่บันทึกแล้ว; login/quota/user draftแสดงการกระทำที่จำเป็นอย่างเจาะจง

### 4. งานค้างนี้

- ตรวจสิทธิ์ของคำขอปกและแท็บปัจจุบันก่อนกู้ ไม่ล้างงาน ไม่สร้างวิดีโอ15ฉากใหม่
- หลังตัวแก้พร้อม เริ่มเฉพาะขั้นเตรียมปกโดยใช้ชื่อและรูปอ้างอิง2ไฟล์เดิม เก็บคำขอเก่าในประวัติ
- ห้ามอาศัยเพียงข้อความerrorเพื่อรีเซตunknown Sendของงานอื่น
