# แผนแนวรีวิวสินค้า Shopee: นิ้วชี้

วันที่: 2026-09-28
สถานะ: แผนเท่านั้น — ยังไม่เปลี่ยนโค้ด โปรแกรมที่เปิดอยู่ Extension หรือคิวงาน

## เป้าหมายและขอบเขต

เพิ่มตัวเลือกชื่อ **นิ้วชี้** ใน `ทำคลิปสินค้าช้อปปี้ > แนวบท` ให้คลิปมีมุมมองคนถือกล้องรีวิวสินค้า เห็นมือชี้รายละเอียดสินค้า โดยไม่ต้องเห็นหน้าคนพูด ใช้ตัวเลือกและหน้าต่างเลือกแนวบทเดิม ไม่เพิ่มหน้าตั้งค่าซับซ้อน และไม่เปลี่ยนค่าเริ่มต้นของแนวเดิม

คำอธิบายใต้ตัวเลือก: **มุมกล้องคนรีวิว เห็นมือชี้สินค้าและรายละเอียด ไม่ต้องเห็นหน้า**

ภาพที่ผู้ใช้ส่งเป็นตัวอย่างมุมกล้องและท่าชี้เท่านั้น ไม่ใช่ภาพอ้างอิงตัวสินค้า และไม่ต้องคัดลอกนาฬิกา สีผิว ฉากหลัง แผงกั้น หรือสิ่งของจากภาพนั้น

## ลักษณะภาพและการเล่า

- มุมมองบุคคลที่หนึ่ง เหมือนถือโทรศัพท์ถ่ายเอง กล้องเคลื่อนไหวเล็กน้อยอย่างเป็นธรรมชาติ ไม่สั่นแรง
- สินค้าจริงตามรูปอ้างอิงเป็นจุดเด่นของเฟรม เห็นมือ/แขนท่อนล่างหนึ่งข้างยื่นจากขอบภาพ ใช้นิ้วชี้ชี้รายละเอียดที่กำลังพูดถึง
- ไม่ใช่ผู้รีวิวที่หันหน้าพูดกับกล้อง ไม่ใช่มุมบุคคลที่สามถ่ายคนถือกล้อง และไม่ใช่ลูกศรหรือสัญลักษณ์นิ้วบนหน้าจอ
- ไม่ให้มือบังรายละเอียดสำคัญหรือฉลาก ไม่สร้างมือหลายข้าง นิ้วเกิน หรืออุปกรณ์เสริมที่ผู้ใช้ไม่ได้เลือก รักษาลักษณะมือ/แขนให้ต่อเนื่องระหว่างฉาก
- ชี้ทีละจุดพร้อมการเคลื่อนไหวสั้น ๆ สลับวางมือ/เข้าใกล้/ถอยกล้องได้ ไม่ต้องค้างท่าชี้เหมือนกันตลอดคลิป
- รีวิวเฉพาะข้อมูลที่มีในสินค้าและรายละเอียดที่เห็นจริง ไม่แต่งราคา ผลทดลอง ประสบการณ์ซื้อ คุณสมบัติ หรือคำรับรองขึ้นเอง
- หากไม่มีตัวละครอ้างอิง ไม่เพิ่มขั้นบังคับเลือกตัวละคร หากมีตัวละครหรือชุดที่บันทึกแล้ว ให้นำมาใช้เฉพาะส่วนมือ/แขน/แขนเสื้อที่เกี่ยวข้อง ไม่บังคับให้เห็นหน้าเต็มตัว
- สินค้าที่เดิมมีคำสั่งบังคับใส่ชุด/โชว์ผู้สวมต้องตรวจความขัดแย้งเป็นพิเศษ แนวนี้เน้นชี้รีวิวตัวสินค้าหรือรายละเอียดผ้า ไม่เปลี่ยนกลับเป็นพรีเซนเตอร์เต็มตัวโดยเงียบ ๆ

จำนวนฉาก อัตราส่วน และผู้ให้บริการใช้ค่าที่ผู้ใช้เลือกไว้ ตัวอย่างจังหวะคือ “เห็นสินค้า → ชี้จุดเด่น → โชว์รายละเอียด/การใช้งานที่รองรับ → สรุป” ไม่ใช่การบังคับให้มีสี่ฉาก และไม่เพิ่มฉากให้คิวเก่า

## เสียงต้องไม่ขัดกับมุมกล้อง

พบใน `core/product_script.py::creative_product_instruction` ว่าโหมดเสียงจากวิดีโอของแนวสร้างสรรค์ปัจจุบันสั่งให้ผู้รีวิว/ตัวละครปรากฏในภาพและพูด จึงเพิ่มแค่ข้อความ “นิ้วชี้” ในแค็ตตาล็อกอย่างเดียวไม่พอ

แผนแก้เฉพาะตัวเลือกใหม่:

- เสียงบรรยายที่ผู้ใช้เลือก: คงเสียงเดิม ให้ความรู้สึกคนถือกล้องบรรยาย ไม่เพิ่มเสียงพูดอีกชุดในวิดีโอ
- เสียงจากผู้ให้บริการวิดีโอ: ผู้รีวิวคนเดียวพูดจากหลังกล้องตามบทที่บันทึก ไม่ขอใบหน้าหรือลิปซิงก์ และไม่เพิ่มผู้พูดคนที่สอง ต้องตรวจความสามารถตามผู้ให้บริการ/โมเดลที่เลือก ไม่สัญญาว่าทุกโมเดลรองรับเท่ากัน
- ไม่มีเสียง: ถ่ายทอดด้วยการชี้และกล้องเท่านั้น ไม่เพิ่มเสียงอัตโนมัติ
- คำพูดต้องแยกจากคำสั่งการเคลื่อนไหว ค่าซับ โลโก้ เพลงและการประกอบ Final ใช้ตัวเลือกเดิม ไม่สร้างข้อความปลอมติดมากับภาพสินค้า

## จุดเชื่อมกับระบบเดิม

1. เพิ่มรหัสเสนอ `pointing_review` พร้อมชื่อ/คำอธิบาย/ข้อกำหนดภาพใน `core/creative_brief.py::PRODUCT_STYLES` ผ่านสัญญา `product_script_options` v3 เดิม ไม่ใช้ `object_pov` เพราะตัวนั้นคือให้สิ่งของเล่าเรื่อง ไม่ใช่มุมกล้องคนรีวิว
2. ใช้ตัวเลือกค้นหาแบบเดิมใน `web_ui/creative_controls.js` และหน้าสินค้า แสดงชื่อที่เลือกและคำอธิบายชัดเจน ไม่เพิ่มช่องตั้งค่าใหม่โดยไม่จำเป็น
3. บันทึกตัวเลือกกับงานที่เตรียมไว้และสำเนาตัวเลือกในคิว ก่อนขอ AI วิเคราะห์ ให้เปิดดูงาน/ทำต่อแล้วคงตัวเลือกเดิม ไม่อ่านค่าหน้าฟอร์มล่าสุดมาทับงานที่บันทึกแล้ว
4. ใน `core/product_script.py` และ `core/product_story.py` แยกคำสั่ง POV/เสียงหลังกล้องเฉพาะแนวนี้ ลดคำสั่งสถานการณ์สมมติหรือการออกหน้ากล้องที่ขัดกับรีวิวแบบถือกล้อง โดยคงข้อมูลสินค้าและรูปอ้างอิงเดิม
5. ส่งข้อกำหนด POV ไปถึงการวิเคราะห์ บท ภาพแต่ละฉาก และคำสั่งวิดีโอ ไม่ฝากไว้แค่ชื่อแนวหรือข้อความสรุปที่ AI อาจละทิ้ง ตรวจผ่าน `core/flow_motion_plan.py`, `core/meta_prompt.py` และคำขอที่ Extension รับจริง
6. ผูกข้อกำหนดกับตัวเลือก/brief ที่บันทึกแล้ว ให้การซ่อมคำตอบหรือกู้ฉากที่ยังไม่สำเร็จยังเป็นนิ้วชี้ ไม่ย้อนเป็นผู้รีวิวหันหน้าพูด และไม่เปลี่ยนสินค้าหรือบทที่อนุมัติแล้ว
7. คงลำดับทำงานทีละฉาก ภาพฉาก N → วิดีโอฉาก N ที่บันทึกสำเร็จ → ฉากถัดไป ตามเส้นทางที่รองรับอยู่ ไม่แก้ตัวจัดคิวหรือเงื่อนไข Send/receipt ในงานเพิ่มแนวรีวิวนี้

งานที่ไม่มีตัวเลือกนี้ต้องใช้พฤติกรรมเดิมทั้งหมด ไม่ย้ายรูปแบบงานเก่าอัตโนมัติ ไม่สร้างภาพ/วิดีโอฉากที่สำเร็จแล้วใหม่ และไม่เปลี่ยนค่าผู้ให้บริการ/โมเดล/เสียงที่บันทึกไว้

## โครงคำสั่งภาพและวิดีโอ

ตัวอย่างแนวคำสั่งที่จะประกอบเข้ากับรายละเอียดฉาก ไม่ใช่พรอมต์ตายตัวสำหรับทุกสินค้า:

> รีวิว [ชื่อสินค้า] จากมุมมองคนถือกล้องเอง ให้สินค้าในภาพอ้างอิงเป็นตัวเด่นและคงรูปลักษณ์เดิม เห็นมือหนึ่งข้างยื่นจากขอบภาพ ใช้นิ้วชี้ชี้ [รายละเอียดที่มีจริงในฉากนี้] อย่างเป็นธรรมชาติ มือไม่บังจุดสำคัญ ไม่เห็นหน้าคนรีวิว กล้องถือด้วยมือเคลื่อนไหวเบา ๆ แล้วเข้าใกล้รายละเอียดตามบท ไม่เพิ่มสรรพคุณ สิ่งของ หรือข้อความที่ไม่มีในข้อมูลสินค้า ใช้รูปแบบเสียงตามตัวเลือกที่บันทึกไว้

ข้อกำหนดระดับงานต้องใช้ซ้ำอย่างคงที่ ส่วนจุดที่ชี้/ระยะกล้อง/การกระทำต้องต่างตามเนื้อหาจริงของแต่ละฉาก

## ลำดับลงมือและเกณฑ์ทดสอบเมื่อได้รับคำสั่งให้ทำ

1. ตรวจฐานรุ่นล่าสุดและการเปลี่ยนแปลงที่อนุมัติแล้วก่อนแก้ ณ การตรวจสำหรับแผนนี้ canonical ระบุ 0.15.460 และมีตัวแก้สะสม 0.15.462 เตรียมแยกไว้ ต้องรักษา 461/462 ไม่เริ่มจากฐานเก่าแล้วทำตัวแก้หล่น รุ่นส่งมอบใหม่ให้ตรวจเลขว่างและจับคู่ desktop/helper/Extension จริงอีกครั้ง
2. เพิ่มตัวเลือกและเงื่อนไขพรอมต์เฉพาะแนวนี้ ทดสอบคำขอที่ประกอบจริง ไม่ใช่ทดสอบเพียงว่ามีชื่อในรายการ
3. เพิ่มชุดตรวจ catalog/v3 validation, UI ค้นหาและเลือก, prepare→queue→job→resume, brief คงเดิม, เสียงทั้งสามแบบ และคำสั่งภาพ/วิดีโอ/กู้ฉากรักษามุม POV
4. ตรวจแนวเดิม standard/story-first/short-film/creative อื่นไม่เปลี่ยนข้อความหรือพฤติกรรม งานไม่มีตัวเลือกใหม่ไม่มีการอัปเกรดข้อมูลโดยอัตโนมัติ และฉากที่เสร็จแล้วไม่ถูกสร้างซ้ำ
5. ตรวจการส่งค่าผ่าน Extension และลำดับฉากเดิมด้วยชุดทดสอบเฉพาะ ก่อนรันทดสอบรวมเมื่อโค้ดนิ่ง อัปเดต blueprint/report และรุ่นคู่ตามกติกาโครงการ ไม่มีการรีโหลดตัวที่กำลังทำงานหรือบิลด์ installer อัตโนมัติ
6. การยืนยันภาพมือ นิ้ว และการเคลื่อนไหวต้องดูผลจริงจากผู้ให้บริการเพิ่มเติม ชุดทดสอบโค้ดพิสูจน์ได้ว่าคำสั่งถูกส่งและเก็บครบ แต่รับประกันคุณภาพภาพที่ AI สร้างไม่ได้ การลองสร้างจริงให้ใช้ขอบเขตที่ได้รับอนุญาตภายหลัง ไม่ส่งงานหรือใช้เครดิตในรอบวางแผนนี้

เกณฑ์รับงาน: เลือก “นิ้วชี้” จากเมนูเดิมแล้วคำขอทุกขั้นเป็นรีวิว POV ที่ใช้สินค้าจริงตามอ้างอิง เสียงไม่บังคับให้เห็นหน้า ทำต่อแล้วยังเป็นแนวเดิม และงาน/แนวเดิมไม่เปลี่ยน

## สิ่งที่ทำในรอบนี้

ตรวจเส้นทางตัวเลือกและการประกอบคำสั่งจากซอร์ส แล้วบันทึกแผนฉบับนี้เท่านั้น ไม่แก้ runtime ไม่เรียกผู้ให้บริการ ไม่ใช้เครดิต ไม่ทดสอบสร้างจริง ไม่แพ็ก/ติดตั้ง Extension และไม่เปิดระบบติดตามที่ผู้ใช้สั่งปิด
