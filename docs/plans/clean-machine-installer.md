# ข้อกำหนดตัวติดตั้งสำหรับเครื่องใหม่

คำสั่งผู้ใช้ 2026-09-17: เมื่อนำ SmartFlow ไปติดตั้งเครื่องอื่น ต้องลงส่วนประกอบที่จำเป็นให้โปรแกรมและ Extension ทำงานได้ครบ ไม่ใช่แพ็กเฉพาะไฟล์เปิดโปรแกรม

## ข้อกำหนดสำหรับการบิลด์ทุกครั้ง

- ตรวจรายการ dependency จากโค้ดและกระบวนการบิลด์จริง รวมทั้งการโหลดไลบรารีแบบ dynamic ไม่อาศัยสิ่งที่บังเอิญติดตั้งในเครื่องพัฒนา
- รวมโปรแกรมหลัก, runtime/ไลบรารีที่ใช้จริง, เครื่องมือประมวลผลสื่อ เช่น FFmpeg/FFprobe เมื่อจำเป็น, ไฟล์หน้า UI, assets, ฟอนต์และโมเดลที่จำเป็นและมีสิทธิ์แจกจ่าย
- รวม Extension รุ่นที่เข้าคู่กับโปรแกรมในตำแหน่งถาวร พร้อมขั้นตอนติดตั้ง/อัปเดตและตรวจการเชื่อมต่อ ไม่ใช้ตำแหน่ง Temp หรือพาธบัญชีผู้พัฒนา
- ตรวจ Chrome และ prerequisite ของระบบที่จำเป็น หากขาดให้ติดตั้งหรือแนะนำผ่านแหล่งทางการที่ตรวจสอบได้ตามสิทธิ์และข้อจำกัดการแจกจ่าย แจ้งส่วนที่ต้องใช้อินเทอร์เน็ตหรือสิทธิ์แอดมินให้ชัด
- เคารพขั้นตอนและการยินยอมของ Chrome; หากต้องให้ผู้ใช้กดอนุญาตหรือโหลด Extension ให้มีขั้นตอนชัดเจน ไม่ปิดการรักษาความปลอดภัยหรืออ้างว่าติดตั้งอัตโนมัติได้โดยยังไม่พิสูจน์
- สร้างโฟลเดอร์ config/cache/log/output และใช้พาธที่ย้ายเครื่องได้ ไม่ฝังพาธ C:/Users/keera หรือพึ่ง environment ของ Codex/เครื่องพัฒนา
- ไม่แพ็กบัญชีผู้พัฒนา, Chrome profile, cookies, API tokens, รหัสผ่าน, งานหรือสื่อส่วนตัว ผู้ใช้ล็อกอินและตั้งค่าบัญชีของตนเอง
- อัปเดตและถอนการติดตั้งต้องรักษางานและการตั้งค่าผู้ใช้ตามนโยบายที่ระบุ พร้อมเส้นทางกู้คืน ห้ามล้างข้อมูลเพื่อให้ติดตั้งผ่าน

## เกณฑ์ยืนยันก่อนส่งมอบ

ทดสอบบนเครื่องหรือ VM Windows สะอาดที่ไม่มีสภาพแวดล้อมนักพัฒนา: ติดตั้ง → เปิดโปรแกรมจากทางลัด → ตรวจรุ่นโปรแกรม/Extension → เชื่อม local bridge → อ่าน/แนบไฟล์และรับผลผ่าน Extension → บันทึก/ประกอบ/เปิดวิดีโอ รวมทั้งเปิดโปรแกรมซ้ำและอัปเดตโดยข้อมูลเดิมไม่หาย

แยกผลทดสอบออฟไลน์ออกจากการสร้างผ่านผู้ให้บริการจริง ค่าใช้จ่าย/บัญชี/สิทธิ์และข้อกำหนดเครื่องต้องระบุ ไม่สรุปว่ารองรับทุกเครื่องจากการทดสอบในเครื่องพัฒนาเพียงเครื่องเดียว

## สถานะ

บันทึกเป็นข้อกำหนดถาวรแล้ว ยังไม่ได้บิลด์ตัวติดตั้งใหม่หรือยืนยัน clean-machine E2E จากคำสั่งให้จำครั้งนี้

## เชื่อมกับแผนสมาชิกและอัปเดต (2026-09-20)

ใช้ [แผนหลัก](smart4-online-membership.md) และ [ลำดับ P0–P6](smartflow-customer-release-roadmap.md) ร่วมกัน ตัวติดตั้งลูกค้าต้องรวม Login/Token และ updater ที่ผ่านการทดสอบพร้อม dependency ครบ ส่วนหน้าออกแพตช์หลังบ้านมี **แพตช์โปรแกรม ZIP + Extension ZIP** เท่านั้น อ่าน signed release.json ภายในแพตช์ ไม่ให้แอดมินอัปโหลด JSON แยก และไม่บังคับ EXE ในการออกแพตช์

EXE Setup ยังจำเป็นสำหรับลูกค้าใหม่และอยู่ส่วนดาวน์โหลด/เผยแพร่ตัวติดตั้งแยกต่างหาก ไม่ได้ยกเลิกงาน clean-machine เมื่อแพตช์ใช้ Extension เดิมต้องตรวจรุ่น/identity/hash ที่ลงลายเซ็นไว้; การอัปโหลด Extension ZIP ไม่แทนการติดตั้ง/อนุญาต/ตรวจรุ่นจริงใน Chrome การแก้เอกสารครั้งนี้ยังไม่บิลด์หรือติดตั้งสิ่งใด
