# SmartFlow AI Extension 0.15.212

วันที่: 2026-09-03

## แก้ไขจากการทดสอบ Google Flow จริง

- รักษาสถานะยืนยันสิทธิ์ที่ตรวจพบระหว่างอัปโหลดของบัญชีใหม่ แม้ Flow จะ re-render ก่อนจบรอบ
- แก้ Worker กู้คืนที่ถูกสถานะ UI ของตัวเองบล็อก จึงกลับมาอนุมัติ ติดตาม และดาวน์โหลดจาก Checkpoint เดิมได้
- ตรวจคำตอบล้มเหลวแบบไม่หักเครดิตพร้อมปุ่ม `ลองอีกครั้ง` ให้ชนะปุ่ม `หยุด` ที่ค้างหลังตรวจยืนยัน 3 รอบ
- รองรับข้อความคิวภาษาไทย `จัดคิวเรียบร้อยแล้ว`, `กำลังรอคิว`, `รอคิว` และ `ความต้องการสูง` เพื่อรอโปรเจกต์เดิมโดยไม่ส่งซ้ำ
- คงกฎแนบรูป → ทำให้เคลื่อนไหว → 9:16/1 ผลลัพธ์ → Prompt → สร้าง เพียงหนึ่งครั้งต่อ Job/Shot/Run

## ความเข้ากันได้

- Extension runtime: `0.15.212`
- Local Bridge required version: `0.15.212`
- Flow helper build: `flow-0.15.212-20260903.1`
- Golden rollback: `0.15.112`
