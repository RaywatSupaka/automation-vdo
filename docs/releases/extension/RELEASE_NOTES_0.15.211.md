# SmartFlow AI Extension 0.15.211

วันที่: 2026-09-03

## แก้ไขจากการทดสอบ Google Flow จริง

- คงสถานะยืนยันสิทธิ์ของบัญชี Google ใหม่จากผลตรวจของขั้นอัปโหลด แม้หน้า Flow จะ re-render ก่อนรอบตรวจสุดท้าย
- หยุดรายงานผิดเป็น `prepare_incomplete` และไม่เปิดโปรเจกต์/อัปโหลดรูปซ้ำขณะรอผู้ใช้ยืนยันสิทธิ์
- ตรวจผลล้มเหลวแบบ “ไม่เรียกเก็บเครดิต” พร้อมปุ่ม `ลองอีกครั้ง` ติดต่อกัน 3 รอบให้ชนะปุ่ม `หยุด` ที่ค้างใน Composer
- Retry เฉพาะช็อตที่ล้มเหลว โดยคง Checkpoint ของคลิปก่อนหน้าและไม่ส่ง Prompt ซ้ำระหว่างเรนเดอร์
- แก้ Worker กู้คืนที่เคยถูกสถานะ UI ของตัวเองบล็อก ทำให้ Extension ค้างรออนุมัติเครดิตทั้งที่โปรแกรมไม่มี Worker เฝ้าอยู่

## ความเข้ากันได้

- Extension runtime: `0.15.211`
- Local Bridge required version: `0.15.211`
- Flow helper build: `flow-0.15.211-20260903.1`
- Golden rollback ยังคงเป็น `0.15.112`
