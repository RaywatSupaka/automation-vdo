# SmartFlow AI Extension 0.15.229

วันที่: 2026-09-04

## แก้ไข

- รองรับปุ่ม ChatGPT Web ภาษาไทยปัจจุบัน `เพิ่มไฟล์และอื่นๆ`
- เลือกช่องอัปโหลดภาพของ Composer โดยตรง แทนการเลือก `input[type=file]` ตัวแรกแบบไม่ระบุหน้าที่
- ใช้ native files setter และส่งทั้ง `input`/`change` event ให้หน้า ChatGPT
- รอหลักฐานว่ารูปอ้างอิงแสดงครบใน Composer ก่อนใส่ Prompt และกดส่ง
- หากอัปโหลดไม่สำเร็จหรือรูปไม่ครบ ระบบหยุดโดยไม่ส่ง Prompt เพื่อป้องกันภาพที่ไม่อ้างอิงสินค้าและไม่ใช้เครดิตเกินจำเป็น
- เพิ่มข้อมูลสถานะ attachment ใน Automation Error Log

## หลักฐานปัญหา

Job `JOB-20260904-830A6F` สร้างภาพที่ 1 ได้ แต่ข้อความสร้างภาพจริงบน ChatGPT ไม่มีไฟล์แนบ ทั้งที่ Extension รายงานว่าแนบแล้ว แสดงว่าเงื่อนไขเดิมใช้เวลา 1.8 วินาทีแทนการตรวจ UI จริง
