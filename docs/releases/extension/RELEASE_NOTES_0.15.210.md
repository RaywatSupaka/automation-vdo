# SmartFlow AI Extension 0.15.210

- เปิด Chrome จากโปรแกรมแบบขยายเต็มจอ และขยายหน้าต่าง Chrome เดิมก่อนส่งงาน
- แก้ลำดับ Google Flow: เปิดเมนูรูปที่อัปโหลดแล้วกด `ทำให้เคลื่อนไหว` ก่อนเลือกรูปหรือกรอก Prompt
- หยุดอย่างปลอดภัยเมื่อไม่พบเมนูสร้างวิดีโอ โดยไม่อัปโหลดรูปหรือกดส่งซ้ำ
- รองรับ Composer ที่สูงขึ้นตามขนาดหน้าจอ ลดการแจ้งผิดว่ารูปยังไม่แนบ
- เก็บเหตุการณ์ Google Flow แบบ JSONL ไว้ที่ `logs/flow_extension.jsonl` ของแต่ละ Job เพื่อวิเคราะห์ครั้งถัดไปได้โดยไม่ต้องเฝ้าหน้าจอตลอด
