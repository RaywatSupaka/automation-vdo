# SmartFlow AI Extension 0.15.206

- บังคับหนึ่ง Job/ช็อต/run กด Generate ได้เพียงครั้งเดียวด้วยใบเสร็จก่อนคลิกจริง
- หากพบ Prompt ของช็อตเดิมในประวัติ Google Flow จะหยุดการกดซ้ำและเฝ้ารอผลเดิม
- Recovery ใช้รูปและ Prompt ที่พร้อมอยู่ใน Composer เดิมทันที ไม่เปิด Media picker หรืออัปโหลดซ้ำ
- จำกัดการเชื่อม Workspace ซ้ำไม่เกิน 2 รอบ และหยุดอย่างปลอดภัยเมื่อไม่พบสถานะภายใน 90 วินาที
- ย้าย Overlay ไปมุมขวาบนและคงสถานะย่อ เพื่อไม่บังช่อง Prompt และปุ่ม Generate
- รักษา Checkpoint และดาวน์โหลดผลลัพธ์เดิมโดยไม่สร้างช็อตที่เสร็จแล้วใหม่
