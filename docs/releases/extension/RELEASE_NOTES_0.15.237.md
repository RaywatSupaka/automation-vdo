# SmartFlow AI Extension 0.15.237

วันที่: 4 กันยายน 2026

## แก้ไข

- แยกคำตอบปฏิเสธของ Gemini เช่น “เป็นแค่โมเดลภาษา” ออกจากกรณีที่มีข้อมูลแต่ JSON เสีย
- เมื่อถูกปฏิเสธ ให้ขอวิเคราะห์ใหม่แบบงานเขียน JSON ล้วนจากข้อมูลและรูปเดิม โดยไม่กล่าวว่าคำตอบก่อนหน้ามีข้อมูล
- ปรับ Master Prompt สินค้าให้สั้นและย้ำว่าไม่ต้องสร้างรูป วิดีโอ หรือเรียกเครื่องมือในขั้นวิเคราะห์
- ใส่ Prompt ผ่านเส้นทาง input ของ editor ก่อน trusted click หนึ่งครั้ง ป้องกันข้อความค้างในช่องทั้งที่ปุ่มส่งพร้อม
- คงกฎแนบรูปเดิม ห้ามแนบซ้ำ ห้าม Enter ซ้ำ และคง Google Flow transaction จากรุ่น `0.15.236`

## หลักฐานบั๊ก

Job `JOB-20260904-8C4A1B` แนบรูปครบ 3 รูปและส่ง Master Prompt สำเร็จ แต่ Gemini ตอบปฏิเสธ จากนั้น Prompt ซ่อม 796 ตัวอักษรค้างใน Composer และระบบหยุดอย่างปลอดภัยโดยไม่ส่งซ้ำ

## สถานะ
