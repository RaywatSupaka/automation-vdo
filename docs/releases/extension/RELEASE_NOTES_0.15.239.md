# SmartFlow AI Extension 0.15.239

สถานะ: Candidate รอทดสอบงานจริงหลังติดตั้ง

## แก้ไข

- รอคำตอบปฏิเสธของ Gemini และ Composer ให้นิ่งก่อนส่ง Prompt กู้คืน JSON
- นับหนึ่ง `user-query` ต่อหนึ่งข้อความจริง ไม่รวม container ซ้อนของ Gemini
- ตรวจ Prompt และตำแหน่งปุ่มส่งซ้ำหลังผูก Trusted click เพื่อกันพิกัดเก่าจาก DOM rerender
- แยก Log เป็นคลิกส่งแล้ว, กำลังรอการยอมรับ และหน้าเว็บรับ Prompt แล้ว
- รอหลักฐานการรับได้นาน 60 วินาที แต่กดส่งเพียงครั้งเดียวและไม่แนบรูปซ้ำ
- หลังหน้าเว็บรับ Prompt วิเคราะห์แล้ว หากคำตอบเริ่มช้าให้เฝ้ารอ turn เดิม ไม่ส่ง Master Prompt และรูปสินค้าอีกรอบ
- ตรวจ `flow_gui_design`, `flow_shot_prompts` และ `spoken_script_segments` ว่าเป็น array ครบตามจำนวนภาพ

## หลักฐานต้นเหตุ

งาน `JOB-20260904-CD2A8C` บน 0.15.238 แนบรูปและใส่ Prompt ครบ จากนั้น Gemini ตอบปฏิเสธและ Extension ส่ง Prompt กู้คืนเร็วเกินจังหวะ DOM หน้าเว็บ เมื่อ Prompt กู้คืนถูกส่งสำเร็จ Gemini ตอบ JSON ครบ จึงยืนยันว่าปัญหาอยู่ที่ readiness/acceptance ของการส่ง ไม่ใช่เนื้อหา Prompt หรือ JSON parser

## กฎความปลอดภัย

- ไม่มีการกดส่งรอบสองอัตโนมัติเมื่อหลักฐานหน้าเว็บมาช้า
- ไม่มีการส่ง Master Prompt ซ้ำหลังยืนยันว่า Gemini รับข้อความแล้ว
- ไม่มีการแนบรูปใหม่ระหว่าง JSON recovery
- หาก Prompt เปลี่ยน ปุ่มขยับหรือถูกบัง จะหยุดก่อน physical click
