# SmartFlow AI Extension 0.15.227

- แก้ช็อตถัดไปค้าง `generation_status_unknown` ทั้งที่รูปและ Prompt พร้อมแล้ว
- เมื่อ inspect พบ Composer พร้อมและยังไม่มีการกดสร้าง/ใบเสร็จ จะคืน AUTO FLOW token แล้วใช้ธุรกรรม Generate เดิมเพียงครั้งเดียว
- ไม่เปิดโปรเจกต์ใหม่ ไม่อัปโหลดรูปซ้ำ และยังรักษา submission receipt ป้องกันการเสียเครดิตซ้ำ
- ลดเวลารอเมนูดาวน์โหลดที่ไม่เริ่มไฟล์จาก 90 วินาทีเหลือ 15 วินาที เพื่อให้ direct URL/เมนูสำรองทำงานเร็วขึ้น
- เวลาดาวน์โหลดไฟล์จริงยังรอได้ถึง 90 วินาที จึงไม่ตัดไฟล์ขนาดใหญ่กลางทาง
- รวมการแก้ Popup changelog ของรุ่น 0.15.226 ไว้ครบ
