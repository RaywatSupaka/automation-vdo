# SmartFlow AI Extension 0.15.230

วันที่: 2026-09-04

## แก้ไข

- ยกเลิกการรีเฟรช Google Flow หลังอัปโหลดรูปครบ 100%
- เลือก asset ที่อัปโหลดเสร็จเข้า Composer ต่อทันทีในหน้าโปรเจกต์เดิม
- ไม่อัปโหลดรูปเดิมซ้ำ หากเลือก asset ไม่สำเร็จจะหยุดอย่างปลอดภัยและให้รันต่อจาก asset เดิม
- รองรับ Checkpoint เก่า `uploaded_waiting_reload` และ `uploaded_reloaded` โดยแปลงเป็นการเลือก asset ในหน้าเดิม ไม่ทำการรีเฟรช
- คงการรีเฟรชหนึ่งครั้งไว้เฉพาะกรณีวิดีโอเรนเดอร์ถึง 100% แต่ผลลัพธ์วิดีโอยังไม่ปรากฏ

## สาเหตุ

Flow หน้าปัจจุบันทำให้ asset พร้อมใช้งานทันทีเมื่ออัปโหลดครบ 100% ลอจิกเดิมสั่ง `location.reload()` หลังจุดนี้ จึงทำลายสถานะ picker/composer ที่พร้อมอยู่แล้วและทำให้เกิดการค้างหรือวนอัปโหลด

## สถานะ

Candidate — ผ่านชุดทดสอบอัตโนมัติ ต้องติดตั้งและทดสอบ Google Flow จริงก่อนเลื่อนเป็น Proven
