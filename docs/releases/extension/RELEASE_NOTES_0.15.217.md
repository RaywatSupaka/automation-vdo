# SmartFlow AI Extension 0.15.217

- โปรแกรมให้เลือกโมเดล ChatGPT Web หรือ Gemini Web ก่อนเริ่มงานสินค้า, Story Shorts, ละคร และคิวหลายเรื่อง
- ค่าโมเดลถูกบันทึกแยกตามผู้ให้บริการและผูกไว้กับ Job/ซีรีส์ เพื่อให้ Resume ใช้ค่าเดิม
- Extension เลือกและตรวจยืนยันโมเดลเพียงครั้งเดียวก่อนส่ง Prompt แรก
- ถ้าไม่พบหรือเลือกโมเดลไม่สำเร็จ ระบบหยุดก่อนส่ง Prompt พร้อมแจ้ง Error ชัดเจน ไม่สลับโมเดลและไม่ส่งซ้ำ
- ย่อ Prompt วิเคราะห์สินค้าโดยคงสัญญา JSON, รูปขายสามภาพ, CGI เฉพาะสินค้า, Google Flow สามช็อต และบท Voice AI ครบ
