# SmartFlow AI Extension 0.15.220

## แก้ Gemini ไม่ตอบ JSON

- คืนการถามจัดรูปแบบ JSON ใหม่เมื่อ Gemini ตอบว่าไม่สามารถช่วยหรือเป็นเพียงโมเดลภาษา
- คำตอบปฏิเสธจะเข้าสู่ลูป `parseOrRepairAnalysis` ทันที ไม่ถูกโยนเป็น no-response ก่อนถึงลอจิกซ่อม
- ส่ง Prompt JSON-only ใหม่สูงสุด 2 รอบ แล้วจึงแจ้ง Error หากยังไม่ผ่าน
- ใช้ ChatGPT/Gemini ตัวเดิมตามที่ผู้ใช้เลือก ห้ามสลับ Provider อัตโนมัติ

## สิ่งที่สืบทอดจาก 0.15.219

- ใช้ลอจิกแนบรูปที่พิสูจน์แล้วจาก `0.15.216` และไม่แนบรูปซ้ำ
- โฟกัส Chrome และกดปุ่มส่งแบบ trusted เพียงครั้งเดียว
- โปรแกรมและ Extension ใช้สัญญาเวอร์ชัน `0.15.220` เดียวกัน
