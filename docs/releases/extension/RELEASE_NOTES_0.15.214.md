# SmartFlow AI Extension 0.15.214

รุ่นลดเวลาส่งต่อระหว่าง Google Flow shots โดยคง Golden upload/submit/download flow เดิม

## ปรับปรุง

- เริ่มตรวจสถานะ Flow ภายใน 2.5 วินาที แล้วใช้รอบตรวจแบบปรับตามสถานะ
- เมื่อเห็นการเรนเดอร์จริง ตรวจทุก 5 วินาที และเมื่อใกล้เสร็จตรวจทุก 2.5 วินาที
- รับไฟล์ทันทีเมื่อ receipt ของ Chrome ยืนยันว่า Job/SHOT/path ตรงและดาวน์โหลดเสร็จแล้ว
- ยังคงตรวจชนิด MP4/WebM และ SHA-256 ก่อนบันทึก Checkpoint
- Worker เดิมเดินเข้าช็อตถัดไปทันทีหลัง commit คลิปก่อนหน้า โดยไม่เสียเวลาตรวจ Remote Checkpoint ที่ยังเกิดขึ้นไม่ได้
- การเปิดโปรแกรมใหม่หรือ Resume ยังคงตรวจ Remote Checkpoint เต็มรูปแบบ เพื่อไม่สร้างวิดีโอซ้ำ

## สิ่งที่ไม่ได้เปลี่ยน

- หนึ่งช็อตต่อหนึ่ง Flow project
- อัปโหลดรูปหนึ่งครั้งและรีเฟรชหนึ่งครั้งตาม Golden flow
- แนบรูปและ Prompt ก่อนกดสร้าง
- กดสร้างและอนุมัติเพียงครั้งเดียว
- ไม่เปิดหลายแท็บ ไม่ส่ง Prompt ซ้ำ และไม่ข้ามการตรวจคลิปซ้ำ
