# SmartFlow AI Extension 0.15.218

## แก้บั๊ก Gemini แนบรูปแล้วไม่ส่ง

- ถอดลอจิกที่นำรูปอ้างอิงจากข้อความเก่ามานับเป็นไฟล์แนบของ Prompt ปัจจุบัน
- เปิดเมนูแนบรูปด้วย trusted click หนึ่งครั้ง และเลือกช่องรับไฟล์ของ Composer ปัจจุบัน
- รอเห็น Preview รูปใหม่ครบตามจำนวนจริงก่อนอนุญาตให้ใส่ Prompt และกดส่ง
- ถ้ารูปไม่ขึ้น ระบบหยุดก่อนกดส่ง จึงไม่สร้างภาพผิดสินค้าและไม่ส่ง Prompt ซ้ำ
- โปรแกรมลองเปิดขั้นแนบรูปใหม่ได้สูงสุดสองรอบเฉพาะกรณีที่พิสูจน์แล้วว่ายังไม่ได้กดส่ง
- รักษานามสกุลไฟล์อ้างอิงให้ตรงกับ MIME จริง (`.jpg`, `.png`, `.webp`)

## เพิ่มหลักฐานสำหรับแก้ปัญหา

- การกดส่งต้องมี trusted click event จริง; หากคลิกไม่ถึงปุ่มจะหยุดโดยไม่คลิกซ้ำ
- Error Log ของ AI Web เก็บ URL, จำนวนรูปแนบ, จำนวนช่องไฟล์, สถานะเมนูอัปโหลด และสถานะปุ่มส่ง
- โปรแกรมแยกชื่อบริการ Gemini Web / ChatGPT Web / Google Flow ตามขั้นที่ล้มเหลว ไม่เหมารวมทุก Error เป็น Google Flow
