# SmartFlow AI Extension 0.15.213

- ยึดใบยืนยันการกดสร้างของแต่ละ Job/SHOT เป็น Checkpoint หลัง Google Flow เปลี่ยนหน้า
- ไม่ประกาศว่า AUTO FLOW สิ้นสุดระหว่างวิดีโออยู่ในคิว
- ไม่ยกเลิกวิดีโอหรือเปิดโปรเจกต์ใหม่เมื่อหน้า Flow โหลดช้าหลังรับงานแล้ว
- ทำต่อและดาวน์โหลดผลเดิมโดยไม่ส่ง Prompt ซ้ำหรือใช้เครดิตซ้ำ
- แก้หน้าโปรแกรมให้แสดงว่า SmartFlow Extension กลับมาออนไลน์ทันที
