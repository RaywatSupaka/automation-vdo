# SmartFlow AI Extension 0.15.223

- แก้โปรแกรมหยุดงานเพราะอ่านการ์ด Error เก่า ทั้งที่รอบใหม่กำลังสร้างหรืออยู่ในคิว
- เมื่อ Flow ยืนยัน failure ใหม่แบบ policy และไม่หักเครดิต โปรแกรมเปลี่ยนพรอมต์ก่อน Retry ไม่ส่งพรอมต์เดิมซ้ำ
- มีพรอมต์ fallback สองระดับต่อช็อต: `policy_safe_v1` และ `policy_minimal_v1`
- ปรับพรอมต์สินค้าเสื้อผ้าให้ใช้เฉพาะทรง คอปก กระดุม ตะเข็บ ผ้าริบและพื้นผิวที่เห็น ไม่ยัด controls, hose หรือ mechanism
- เก็บคลิปช็อตที่เสร็จแล้วและรูปเดิมไว้ทั้งหมด Retry เฉพาะช็อตที่ล้มเหลว
- ซิงก์ Extension และ Local Bridge เป็น 0.15.223
