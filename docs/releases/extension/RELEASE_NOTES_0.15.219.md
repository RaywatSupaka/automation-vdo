# SmartFlow AI Extension 0.15.219

## จุดแก้หลัก

- คืนลอจิกแนบรูปของ `0.15.216` ที่ใช้งานได้จริง: รูปที่ Gemini รับไว้แล้วสามารถใช้ต่อจาก user turn เดิมได้
- ยกเลิกลอจิกของ `0.15.218` ที่บังคับเปิดเมนูแนบและรอ Preview ใหม่ จึงไม่แนบรูปซ้ำและไม่วนอยู่ขั้นอัปโหลด
- ก่อนกดส่ง ระบบ focus หน้าต่างและแท็บ AI Web ตรวจว่าปุ่มไม่ถูก Overlay บัง แล้วกดแบบ trusted เพียงหนึ่งครั้ง
- ตรวจหลักฐานว่า trusted click ถึงปุ่มจริง; ถ้าไม่ถึงจะหยุดโดยไม่กดซ้ำ
- คงการเลือกโมเดล ChatGPT/Gemini ตามค่าที่ผู้ใช้เลือกในโปรแกรม
- Error Log ยังคง URL และข้อมูลหน้าจอแบบจำกัดความยาวเพื่อวิเคราะห์ได้ โดยไม่เก็บข้อมูลเข้าสู่ระบบ

## กฎความปลอดภัย

- ไม่กด Enter หรือปุ่มส่งซ้ำเมื่อหน้าเว็บตอบช้า
- ไม่เปิดเมนูแนบใหม่ถ้ารูปอ้างอิงมีอยู่แล้ว
- ไม่สลับ ChatGPT/Gemini เอง

## สถานะ

- `0.15.218` ถูกถอนจากการแนะนำติดตั้งเพราะวิเคราะห์สถานะรูปแนบผิด
- Runtime ที่โปรแกรมต้องใช้คือ `0.15.219`
