# SmartFlow AI Extension 0.15.226

- รองรับ Popup บันทึกการเปลี่ยนแปลงของ Google Flow ที่มีปุ่ม `ดูบันทึกการเปลี่ยนแปลงทั้งหมด` และ `เริ่มต้นใช้งาน`
- กด `เริ่มต้นใช้งาน` ด้วย trusted click เพียงครั้งเดียวเมื่อยืนยันได้ว่าเป็น changelog dialog จริง
- ตรวจทั้งก่อนเตรียมรูป/Prompt และระหว่างเฝ้ารอผลวิดีโอ เพื่อไม่ให้ Popup บังขั้นตอนถัดไป
- ไม่รีเฟรชหน้า ไม่เปิดแท็บใหม่ ไม่ส่ง Prompt ซ้ำ และไม่แตะหน้าต่างอนุมัติเครดิตหรือสิทธิ์รูป
- คงลอจิกแนบรูปและสร้างวิดีโอของรุ่น 0.15.225 ไว้เหมือนเดิม
