SmartFlow AI — รุ่นทดสอบ Beta

ตัวติดตั้ง Windows 64 บิต รวม Python และเครื่องมือวิดีโอ/มือถือแล้ว ต้องใช้อินเทอร์เน็ตสำหรับเข้าสู่ระบบและบริการ AI รุ่นนี้ยังต้องทดสอบบนคอมพิวเตอร์เครื่องใหม่ก่อนแจกใช้งานทั่วไป

1. เปิดโปรแกรมและเข้าสู่ระบบ

เปิด SmartFlow AI จากเมนู Start แล้วกรอก Token ที่แอดมินออกให้ หนึ่ง Token ใช้กับหนึ่งเครื่อง บัญชี ChatGPT/Gemini/Google Flow ใช้ของคุณเอง บริการภายนอกอาจมีค่าสมาชิกหรือเครดิต ไม่มี Token หรือบัญชีของผู้พัฒนาติดมากับชุดนี้

2. เชื่อมต่อ Chrome Extension

ใช้ Google Chrome และเข้าสู่ระบบบริการ AI ตามปกติ หลังเปิด SmartFlow ครั้งแรก ให้เปิดหน้าจัดการส่วนขยายของ Chrome เปิดโหมดนักพัฒนา เลือก “โหลดส่วนขยายที่แตกไฟล์แล้ว” แล้วเลือกโฟลเดอร์ %LOCALAPPDATA%\SmartFlowAI\data\browser_extension ส่วนขยาย SmartFlow ไม่ต้องกรอก Token แยก

Chrome ต้องให้ผู้ใช้อนุญาตติดตั้งเอง หากมี SmartFlow Extension อยู่แล้ว อย่าลบหรือติดตั้งซ้ำหลายตัว ให้ใช้โปรไฟล์เดิมและโฟลเดอร์ถาวรเดิม อัปเดต/โหลดใหม่เฉพาะเมื่องานหยุดแล้ว ไม่คัดลอกโปรไฟล์หรือคุกกี้ไปอีกเครื่อง

3. คลิปและโทรศัพท์

รวม FFmpeg, ADB และ scrcpy ในตัวติดตั้งแล้ว การโพสต์ Shopee ผ่าน Wi-Fi ต้องเปิด Wireless debugging ปลดล็อกมือถือ และอยู่ในเครือข่ายที่คอมพิวเตอร์เข้าถึงได้ คอมต่อสาย LAN ได้ ไม่จำเป็นต้องเสียบ USB ตลอดเวลา เลือกและยืนยันเครื่องในโปรแกรมก่อนโพสต์

ไฟล์งาน รูป เพลงและข้อมูลลูกค้าในเครื่องผู้พัฒนาไม่รวมในตัวติดตั้ง คุณนำเข้าเพลง/สื่อที่มีสิทธิ์ใช้งานเองได้

4. ข้อมูลและการอัปเดต

โปรแกรมอยู่ที่ %LOCALAPPDATA%\Programs\SmartFlowAI ข้อมูลอยู่ที่ %LOCALAPPDATA%\SmartFlowAI\data การถอนการติดตั้งไม่ลบข้อมูลงาน ให้สำรองข้อมูลก่อนเปลี่ยนเครื่องหรืออัปเดต และรอให้งานสร้างคลิป/โพสต์หยุดก่อน

5. สิ่งที่ต้องทราบ

หากเครื่องไม่มี Microsoft WebView2 Runtime ตัวติดตั้งจะขอติดตั้งจาก Microsoft โดยต้องต่ออินเทอร์เน็ต หากติดตั้งไม่ได้จะหยุดพร้อมแจ้งเหตุผล ไม่รายงานว่าสำเร็จทั้งที่เปิดโปรแกรมไม่ได้

ไฟล์โปรแกรมรุ่นทดสอบยังไม่มีลายเซ็นผู้เผยแพร่ Windows อาจแจ้งเตือน ให้ตรวจแหล่งที่มาและ SHA-256 ก่อน ไม่ควรปิดระบบรักษาความปลอดภัย ชุดนี้ยังไม่ถือว่าผ่านการทดสอบบัญชีจริง การสร้าง AI จริง และอัปเดตข้ามรุ่นบนเครื่องใหม่

ประกาศลิขสิทธิ์ไลบรารีและฟอนต์อยู่ใน licenses พร้อมเอกสาร FFmpeg ใน ffmpeg และ scrcpy ใน tools\android
